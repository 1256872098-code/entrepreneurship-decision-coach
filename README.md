# 全国创业决策仿真 Skill

这是一个正在迭代的 Codex Skill，用于根据每期市场形势、本企业状态以及上一期其他企业的决策与结果，生成全国创业决策仿真的完整填报建议。

当前版本先完成最小骨架，并记录：

- 第 1 周期市场形势报告；
- 决策界面的 24 个字段和单位；
- 图2中当前展示的数值；
- 首期与后续期的输入差异；
- 等待补充的正式决策规则。

Skill 位于 [`entrepreneurship-simulation-decision/`](entrepreneurship-simulation-decision/)。后续规则统一维护在 [`references/rules.md`](entrepreneurship-simulation-decision/references/rules.md)。
